# personal-organizzer · Central de Gestão

Ferramenta de gestão pessoal em um único arquivo HTML, sem servidor e sem instalação.

- **Abrir:** dê dois cliques em `gestao_pessoal_v13.html` (Chrome ou Edge recomendados, para salvar direto no arquivo).
- **Dados:** ficam num arquivo JSON separado, criptografado com AES-GCM 256 e senha. O HTML não guarda nenhum dado, então pode ser atualizado à vontade.
- **Atualizar de versão:** abra o arquivo de dados atual na versão nova. A migração é automática e um backup do arquivo anterior é baixado.

## Telas

| Tela | Para quê |
|---|---|
| Hoje | Tarefas do dia, atrasos, fóruns dos próximos 7 dias e iniciativas pedindo atenção |
| Iniciativas | Acompanhamento diário: feito × prazo, fase, próximo entregável e atualização de uma linha |
| Demandas | Lista e quadro de tarefas |
| Roadmap | Horizontes, linha do tempo e dependências |
| Delegação | O que está com quem, prazos, cobranças e aderência |
| Fóruns | Reuniões recorrentes, pautas acumuladas por data, reunião, decisões e compromissos; aba Acordos para compartilhar |
| Staff | Semana dos times, backlog e pauta da staff |
| Pessoas | 1:1, feedback e times |
| Métricas | Carga, aderência e histórico semanal |
| Time (clique no nome de um time) | Visão do time: resumo do backlog, entregáveis por iniciativa, entregas da semana e tarefas das iniciativas; reunião de status guiada; folha para compartilhar no Teams |

O plano da versão atual está em [`docs/plano-v13.md`](docs/plano-v13.md) (a anterior, em [`docs/plano-v12.md`](docs/plano-v12.md)). As versões anteriores ficam em `legacy/` como referência.
